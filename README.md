# Carrito de Compras con Vue y LocalStorage

## 📝 Descripción del Proyecto
Aplicación web interactiva de comercio electrónico centrada en la gestión de un carrito de compras. Desarrollada con **Vue.js**, implementa persistencia de datos utilizando **LocalStorage** para que los productos seleccionados no se pierdan al recargar o cerrar el navegador.

## 🚀 Características Principales
* **Gestión de Carrito:** Agregar, eliminar y actualizar cantidades de productos en tiempo real.
* **Persistencia de Datos (LocalStorage):** El estado del carrito se guarda automáticamente en el almacenamiento local del navegador.
* **Cálculo Dinámico:** Actualización automática de subtotales, cantidades totales y monto final a pagar.
* **Interfaz Dinámica (Vue.js):** Reutilización de componentes y reactividad fluida para una excelente experiencia de usuario.

## 🛠️ Tecnologías Utilizadas
* **Vue.js** (Framework progresivo para la interfaz y reactividad)
* **JavaScript (ES6+)** (Lógica de negocio y manipulación de estado)
* **LocalStorage API** (Persistencia de datos del lado del cliente)
* **HTML5 & CSS3** (Maquetación y estilos)
